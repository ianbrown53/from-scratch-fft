# from-scratch-fft

## About

Trying to write my own FFT algorithm from scratch without help to brush up on C++ and DSP fundamentals.

## How to Run

### Build

From the project root:

```bash
mkdir -p build
cd build
cmake ..
cmake --build .
```

### Run Main

```bash
./from-scratch-fft
```

### Run Tests
```bash
./test_fft
```
